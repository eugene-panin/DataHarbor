# Gemini CLI / Antigravity

Agent contract for this repo is **agent-agnostic** and lives in [`AGENTS.md`](AGENTS.md).

1. Read **AGENTS.md §0** (skill routing).
2. Load **one** matching skill from `.agents/skills/<name>/SKILL.md`.
3. Optional: `harbor skill install` copies skills into `~/.gemini/config/skills` and `~/.gemini/skills`.
